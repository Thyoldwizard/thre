# Changelog

All notable changes to this project will be documented here.

## 1.0.0 - 2026-06-01

### Added

- Initial open-source release of thre.
- SwiftUI app for three-task daily focus.
- SwiftData models for tasks, subtasks, daily records, and reflections.
- Dark studio design system.
- Onboarding, home, add task, task detail, schedule, rhythm, reflection, carry-forward, transcendence, and settings flows.
- WidgetKit widgets and ActivityKit Live Activity surfaces.
- App Intents, share extension, Spotlight indexing, reminders, haptics, and local preferences.
- Unit and UI test targets.
- Screenshot set for documentation and visual QA.

### Changed

- Repository documentation rewritten for open-source use.
- Fake third-party sign-in UI removed from onboarding.

### Security

- Documented local-first privacy baseline and vulnerability reporting process.
