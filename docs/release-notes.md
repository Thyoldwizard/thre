# Release Notes

## 1.0.0

Initial open-source release of thre.

### Highlights

- Native SwiftUI implementation of a three-task daily focus workflow.
- SwiftData models for tasks, subtasks, daily records, and reflections.
- Dark studio design system and polished iPhone-first screens.
- Widgets, Live Activities, App Intents, reminders, share extension support, and Spotlight indexing.
- Local-first privacy baseline with no analytics, backend sync, or third-party auth.
- Unit and UI test targets.
- Screenshot set for documentation and visual QA.

### Known Limitations

- App Store distribution is not configured in this repository.
- The Xcode project retains the internal `Ember` codename in target names and bundle identifiers.
- CI depends on GitHub-hosted macOS/Xcode runner availability.
- iPad-specific layouts are not a primary focus yet.
